## Files To Add To The Repository

The repository already has `index.html` and `style.css`.

Add these remaining files:

- Copy `bride-script.js` to `script.js`
- Copy `bride-github-workflows-static.yml` to `.github/workflows/static.yml`
- Copy `bride-README.md` to `README.md`

## Deploy To GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, select **GitHub Actions**.
4. Push the files to `main`.
5. Open the **Actions** tab and wait for **Deploy static content to Pages** to finish.
6. The site will publish at:

```text
https://logansmith904.github.io/Usman-s-Wedding-Bride/
```
